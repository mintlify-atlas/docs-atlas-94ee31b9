The quotation wizard guides users through a 5-step process to create complete, professional air conditioning quotations. Each step validates data before allowing progression, ensuring all required information is captured.

## 5-Step Workflow

The wizard consists of five distinct steps, each focusing on a specific aspect of the quotation:

<Steps>
  <Step title="Equipment Selection">
    Select air conditioning equipment with filtering by brand, BTU capacity, and refrigerant type.
  </Step>
  <Step title="Service Type">
    Choose from 6 service types: installation, maintenance, replacement, repair, warranty, or quote-only.
  </Step>
  <Step title="Accessories & Extras">
    Add optional accessories like piping kits, electrical components, and installation materials.
  </Step>
  <Step title="Client Information">
    Capture complete client details including contact info, installation address, and GPS location.
  </Step>
  <Step title="Summary & PDF">
    Review the complete quotation, apply discounts, and generate a professional PDF document.
  </Step>
</Steps>

### Step Management Logic

The `goToStep()` function handles all navigation between steps:

```javascript {10-19} title="app.js"
function goToStep(n) {
  for (let i=1; i<=5; i++) {
    document.getElementById('page'+i).classList.toggle('active', i===n);
    document.getElementById('nav'+i).classList.toggle('active', i===n);
    const dot = document.getElementById('sd'+i);
    const lbl = document.getElementById('sl'+i);
    dot.className = 'step-dot ' + (i < n ? 'done' : i === n ? 'active' : '');
    lbl.className = 'step-label ' + (i < n ? 'done' : i === n ? 'active' : '');
    
    // Mark completed steps with checkmark
    dot.textContent = i < n ? '✓' : i;
    
    if (i < 5) {
      document.getElementById('sline'+i).className = 'step-line ' + (i < n ? 'done' : '');
    }
  }
  
  currentStep = n;
  window.currentStep = currentStep;
  
  // Trigger step-specific logic
  if (n === 2) {
    preloadInstallationsFromEquipment();
    renderServiceChip();
  }
  
  window.scrollTo(0,0);
}
```

<Note>
  The wizard automatically scrolls to the top when changing steps to ensure the user sees the entire form.
</Note>

## Step Validation

Each step validates required data before enabling the "Next" button:

### Step 1: Equipment Validation

```javascript {3-6} title="app.js"
function updateStep1NextButton() {
  const btn = document.getElementById('btnStep1Next');
  if (!btn) return;
  
  const hasItems = getSelectedEquipmentItems().length > 0;
  
  btn.disabled = !hasItems;
  btn.style.opacity = hasItems ? '1' : '0.4';
}
```

### Step 2: Service Validation

```javascript {4-7} title="app.js"
function updateStep2NextButton() {
  const btn = document.getElementById('btnStep2Next');
  if (!btn) return;
  
  const hasMulti = (serviceQtyMap.instalacion || 0) > 0 || (serviceQtyMap.mantencion || 0) > 0;
  const hasSingle = !!selectedService;
  const enabled = hasMulti || hasSingle;
  
  btn.disabled = !enabled;
  btn.style.opacity = enabled ? '1' : '0.4';
}
```

<Info>
  Steps 3 (Accessories) and 4 (Client) do not require validation - users can proceed with or without adding accessories, and client information is optional.
</Info>

## Smart Pre-filling

The wizard automatically pre-fills installation quantities based on equipment selection:

```javascript {6-11} title="app.js"
function preloadInstallationsFromEquipment() {
  const equipCount = getEquipCount();
  
  if (equipCount === 0) {
    serviceQtyMap.instalacion = 0;
  } else if ((serviceQtyMap.instalacion || 0) === 0) {
    // Pre-load default: 1 installation per equipment added
    serviceQtyMap.instalacion = equipCount;
  } else {
    // Clamp if user removed equipment after setting installations
    serviceQtyMap.instalacion = Math.min(serviceQtyMap.instalacion, equipCount);
  }
  
  updateMultiServiceInputs();
  updateStep2NextButton();
  renderServiceGrid();
}
```

<Tip>
  When a user adds 3 air conditioning units in Step 1, the system automatically suggests 3 installations in Step 2, saving time and reducing errors.
</Tip>

## Equipment Summary Chip

When moving to Step 2, a summary chip displays selected equipment:

```javascript {6-16} title="app.js"
function renderServiceChip() {
  const chip = document.getElementById('acSelectionChip');
  const selectedItems = getSelectedEquipmentItems();
  if (!selectedItems.length) { chip.innerHTML = ''; return; }
  
  const equipCount = selectedItems.reduce((sum, item) => sum + item.qty, 0);
  const equipTotal = selectedItems.reduce((sum, item) => 
    sum + (item.cap.price_with_tax * item.qty), 0);
  
  chip.innerHTML = `
    <div class="selection-chip">
      <div class="chip-icon"><i class="fas fa-snowflake"></i></div>
      <div class="chip-info">
        <div class="chip-title">Equipos seleccionados: ${equipCount}</div>
        <div class="chip-sub">${selectedItems.slice(0, 2).map(item => 
          `${item.ac.brand_model} ${(item.btu/1000).toFixed(0)}K x${item.qty}`
        ).join(' · ')}${selectedItems.length > 2 ? ' ...' : ''}</div>
      </div>
      <div class="chip-price">$${fmtNum(equipTotal)}</div>
    </div>`;
}
```
