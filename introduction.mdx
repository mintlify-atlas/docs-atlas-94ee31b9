## How It Works

CotizaClima follows a simple 5-step workflow:

<Steps>
  <Step title="Select Equipment">
    Browse the equipment catalog and select air conditioning units. Filter by brand (LG, Midea, TCL, etc.), BTU capacity (9,000 to 36,000), and refrigerant type.
  </Step>
  
  <Step title="Choose Service Type">
    Select the service you're quoting: new installation, maintenance, equipment change, repair, warranty visit, or budget quote.
  </Step>
  
  <Step title="Add Accessories">
    Include optional accessories and extras in your quote.
  </Step>
  
  <Step title="Enter Client Details">
    Capture client information including name, RUT, contact details, installation address (with GPS support), and property type.
  </Step>
  
  <Step title="Review and Generate">
    Review the complete quote, adjust pricing if needed, apply discounts, and generate a professional PDF.
  </Step>
</Steps>

## Technology Stack

CotizaClima is built with modern web technologies:

- **Frontend**: Vanilla JavaScript with modular architecture
- **Database**: Firebase Realtime Database for equipment catalog and quote storage
- **Authentication**: Firebase Authentication for secure user sessions
- **PDF Generation**: jsPDF library for professional quote documents
- **Styling**: Custom CSS with responsive design
- **Icons**: Font Awesome icon library
