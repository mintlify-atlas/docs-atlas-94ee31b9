CotizaClima uses a 5-step wizard to guide you through creating professional air conditioning installation quotes. Each step collects specific information to build a complete, accurate quotation.

## Quote Creation Workflow

The quote creation process is structured as a multi-step form with visual progress tracking:

<Steps>
  <Step title="Select Equipment">
    Browse and select air conditioning units from the equipment catalog. Filter by brand, BTU capacity, or refrigerant type.
  </Step>
  
  <Step title="Choose Service Type">
    Select the type of service: installation, maintenance, repair, or equipment change. Specify quantities for each service type.
  </Step>
  
  <Step title="Add Accessories">
    Optionally add accessories and extras like copper piping, installation kits, or additional components.
  </Step>
  
  <Step title="Enter Client Information">
    Fill in complete client details including name, address, contact information, and property type.
  </Step>
  
  <Step title="Review and Generate">
    Review the complete quote, adjust pricing if needed, apply discounts, and generate the final PDF.
  </Step>
</Steps>

### Selecting Multiple Units

You can select multiple equipment units with different capacities:

```javascript
function equipKey(idx, btu) {
  return `${idx}__${btu}`;
}

function getSelectedEquipmentItems() {
  return Object.entries(selectedEquipments)
    .map(([key, qty]) => {
      const [idxStr, btuStr] = key.split('__');
      const idx = Number(idxStr);
      const btu = Number(btuStr);
      const ac = allAC[idx];
      if (!ac || !qty) return null;
      const cap = (ac.capacities || []).find(c => 
        Number(c.btu_capacity) === btu
      );
      if (!cap) return null;
      return { key, idx, btu, qty, ac, cap };
    })
    .filter(Boolean);
}
```

<Tip>
  You can add multiple quantities of the same equipment model if your client needs multiple units for different rooms.
</Tip>

### Service Quantities

For installation and maintenance, specify how many service instances you need:

```javascript
let serviceQtyMap = { instalacion: 0, mantencion: 0 };

function preloadInstallationsFromEquipment() {
  const equipCount = getEquipCount();
  if (equipCount === 0) {
    serviceQtyMap.instalacion = 0;
  } else if ((serviceQtyMap.instalacion || 0) === 0) {
    // Default: 1 installation per equipment
    serviceQtyMap.instalacion = equipCount;
  } else {
    // Clamp if user removed equipment
    serviceQtyMap.instalacion = Math.min(
      serviceQtyMap.instalacion, 
      equipCount
    );
  }
}
```

<Note>
  By default, CotizaClima automatically sets the installation quantity to match the number of equipment units selected in Step 1.
</Note>

## Step 3: Adding Accessories

Add optional accessories and extras to the quote. Accessories are loaded from Firebase and can include:

- Copper piping extensions
- Installation kits
- Mounting brackets
- Electrical components
- Drain lines and accessories

```javascript
// Accessories are stored in state
let accQty = {}; // { accessoryId: quantity }

function getAccessoryTotal() {
  return Object.entries(accQty).reduce((sum, [id, qty]) => {
    const acc = accessories.find(a => a.id === id);
    return sum + (acc ? acc.price * qty : 0);
  }, 0);
}
```

<Info>
  This step is optional. You can skip it if no additional accessories are needed for the installation.
</Info>


```javascript
function recalcTotal() {
  const equipPrice = Number($('sumEquipPrice').value || 0);
  const servicePrice = Number($('sumServicePrice').value || 0);
  const extrasTotal = getExtrasTotal();
  const subtotal = equipPrice + servicePrice + extrasTotal;
  
  const discountPct = Number($('discountPct').value || 0);
  const discountAmt = Math.round(subtotal * (discountPct / 100));
  const grandTotal = subtotal - discountAmt;
  
  $('discountBadgeAmt').textContent = `— $${fmtNum(discountAmt)}`;
  $('grandTotal').textContent = fmtNum(grandTotal);
}
```

## Saving vs. Issuing Quotes

CotizaClima distinguishes between draft and issued quotes:

<CardGroup cols={2}>
  <Card title="Save Draft" icon="floppy-disk">
    Saves the current quote as a draft without generating PDF. Useful for incomplete quotes or quotes pending approval.
    
    **Status**: `draft`
    
    **Requires**: Authentication
  </Card>
  
  <Card title="Issue Quote" icon="file-pdf">
    Generates PDF and marks quote as issued. This is the final, client-ready version.
    
    **Status**: `issued`
    
    **Requires**: Authentication (optional)
  </Card>
</CardGroup>

### Saving a Draft

```javascript
async function saveDraftQuote() {
  return persistCurrentQuote('draft', { 
    requireAuth: true, 
    silent: false 
  });
}
```

```html

  <i class="fas fa-floppy-disk"></i> Guardar borrador

```

### Auto-Save on PDF Generation

When you generate a PDF while authenticated, the quote is automatically saved:

```javascript
function patchGeneratePdfForAutosave() {
  const original = window.generatePDF;
  window.generatePDF = async function patchedGeneratePDF() {
    let saved = null;
    try {
      saved = await persistCurrentQuote('issued', { 
        requireAuth: false, 
        silent: true 
      });
    } catch (e) {
      saved = null;
    }
    
    await original();
    
    if (saved) {
      showToast('PDF generado y cotización guardada', 'success');
    }
  };
}
```

<Info>
  You can generate PDFs without being authenticated, but the quote won't be saved to your history.
</Info>

## Starting a New Quote

After completing a quote, click "Nueva cotiz." to reset and start fresh:

```html
<button class="btn btn-danger" onclick="resetAll()">
  <i class="fas fa-rotate-right"></i> Nueva cotiz.
</button>
```

This clears all selections and returns to Step 1 with a new quote number.
