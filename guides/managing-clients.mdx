CotizaClima automatically builds a client directory as you create and save quotes. The client directory page (`clients.html`) provides a centralized view of all your clients and their associated quotes.

## How Clients Are Created

Clients are automatically created when you save a quote that includes a **RUT** (Chilean tax ID).

### Client Deduplication

CotizaClima uses the RUT as a unique identifier to prevent duplicate clients:

```javascript
// Normalizes a Chilean RUT: removes dots and spaces
// "12.345.678-9" → "12345678-9"
function normalizeRut(rut) {
  if (!rut || typeof rut !== 'string') return '';
  return rut.replace(/\./g, '')
             .replace(/\s/g, '')
             .toLowerCase()
             .trim();
}

// Returns a stable clientId based on RUT
function resolveClientId(client) {
  if (!client) return null;
  const rut = normalizeRut(client.rut || '');
  // Require at least one digit + hyphen + digit
  if (!rut || !/\d/.test(rut) || rut.length < 3) return null;
  return rut;
}
```

<Info>
  If you create multiple quotes for the same client (same RUT), CotizaClima automatically associates all quotes with that single client record.
</Info>

### Client Sync on Quote Save

When you save a quote, the client is synced in the background:

```javascript
// Called fire-and-forget from persistCurrentQuote
async function syncClientForQuote(uid, idToken, clientObject, quoteId) {
  if (!clientObject || !clientObject.name) return null;
  const clientId = resolveClientId(clientObject);
  if (!clientId) return null; // No RUT → skip
  
  try {
    const now = Date.now();
    
    // Fetch existing to preserve createdAt and quoteIds
    let existing = null;
    try {
      existing = await request(
        'clients/' + uid + '/' + clientId, 
        idToken, 
        { method: 'GET' }
      );
    } catch (e) {
      existing = null;
    }
    
    const quoteIds = Object.assign({}, 
      existing ? (existing.quoteIds || {}) : {}
    );
    if (quoteId) quoteIds[quoteId] = true;
    
    const payload = {
      name: clientObject.name || '',
      rut: clientObject.rut || '',
      rutKey: clientId,
      phone: clientObject.phone || '',
      email: clientObject.email || '',
      address: clientObject.address || '',
      city: clientObject.city || '',
      region: clientObject.region || '',
      property: clientObject.property || '',
      notes: clientObject.notes || '',
      createdAt: (existing && existing.createdAt) 
        ? existing.createdAt 
        : now,
      updatedAt: now,
      quoteIds: quoteIds
    };
    
    await request('clients/' + uid + '/' + clientId, idToken, {
      method: 'PUT',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify(payload)
    });
    
    return clientId;
  } catch (e) {
    // Silently fail — background operation
    return null;
  }
}
```

<Note>
  Client sync happens in the background and won't interrupt your workflow if it fails. However, only quotes with a RUT will create/update client records.
</Note>

## Searching and Filtering Clients

Use the search bar to quickly find clients by name or RUT.

### Real-Time Search

The search filters clients in real-time as you type:

```javascript
function renderFiltered(query) {
  var q = (query || '').trim().toLowerCase();
  var filtered = q
    ? allClients.filter(function(c) {
        return (c.name || '').toLowerCase().indexOf(q) !== -1 ||
               (c.rut || '').toLowerCase().indexOf(q) !== -1 ||
               (c.rutKey || '').toLowerCase().indexOf(q) !== -1;
      })
    : allClients;
  
  var container = document.getElementById('clientList');
  if (!container) return;
  
  if (!filtered.length) {
    container.innerHTML = 
      '<div class="quote-item" style="text-align:center;padding:16px;">' +
      (q ? 'Sin resultados para &ldquo;' + q + '&rdquo;.' 
         : 'No hay clientes guardados aún.') +
      '</div>';
    return;
  }
  
  container.innerHTML = filtered
    .map(function(c) { 
      return renderClientCard(c, quotesByClientId[c.id] || []); 
    })
    .join('');
}

// Bind search input
document.getElementById('clientsSearchInput')
  .addEventListener('input', function() {
    renderFiltered(this.value);
  });
```

<Tip>
  The search matches both formatted RUTs (e.g., "12.345.678-9") and normalized RUTs (e.g., "12345678-9"), so you can search either way.
</Tip>

Click the toggle button on a client card to expand and view all quotes for that client.

// Toggle client accordion

## GPS Location Features

CotizaClima integrates GPS features for quick access to client locations.

### Waze Navigation

Each client card and quote includes a Waze button for one-tap navigation:

```javascript
function buildWazeUrl(obj) {
  var parts = [obj.address, obj.city, obj.region].filter(Boolean);
  if (!parts.length) return '';
  return 'https://waze.com/ul?q=' + 
         encodeURIComponent(parts.join(', ')) + 
         '&navigate=yes';
}

var wazeUrl = buildWazeUrl(client);
var wazeBtn = wazeUrl
  ? '<a class="quotes-btn secondary icon-btn" ' +
       'href="' + wazeUrl + '" ' +
       'target="_blank" ' +
       'rel="noopener noreferrer" ' +
       'title="Navegar con Waze">' +
      '<i class="fas fa-route"></i>' +
    '</a>'
  : '';
```

<Tip>
  The Waze button automatically combines the client's address, city, and region to create a complete navigation query.
</Tip>

### Quote Loading in Editor

When you return to the main app, the pending quote is automatically loaded:

```javascript
function applyPendingQuoteIfAny() {
  const bridge = getBridge();
  if (!bridge) return;
  
  const payload = readPendingQuote();
  if (!payload || !payload.quote) return;
  
  const originalToast = window.showToast;
  window.showToast = function() {};
  try {
    bridge.importQuoteSnapshot(payload.quote);
  } finally {
    window.showToast = originalToast;
    clearPendingQuote();
  }
  
  showToast('Cotización cargada para edición', 'success');
}
```

<Note>
  Opening a quote from the client directory loads all its data into the quote editor, allowing you to make changes and re-generate the PDF or save an updated version.
</Note>

### Data Quality Tips

<Accordion title="RUT Formatting">
  CotizaClima accepts RUTs in any format:
  - With dots: `12.345.678-9`
  - Without dots: `12345678-9`
  - With spaces: `12 345 678-9`
  
  All formats are normalized to the same internal format for deduplication.
</Accordion>

<Accordion title="Phone Number Best Practices">
  Include the country code for international clients:
  - Chilean mobile: `+56 9 1234 5678`
  - Chilean landline: `+56 2 1234 5678`
  
  This ensures the quick call feature works correctly.
</Accordion>

<Accordion title="Address Accuracy">
  For best results with GPS features:
  - Include street number
  - Specify commune (comuna)
  - Add apartment or office number if applicable
  - Use standard abbreviations (Av., Pje., etc.)
</Accordion>

## Troubleshooting

<Accordion title="Client not appearing in directory">
  **Possible causes:**
  - Quote was saved without a RUT
  - RUT was invalid or too short (minimum 3 characters)
  - Not authenticated when saving the quote
  
  **Solution:** Edit the quote, add a valid RUT, and save again while authenticated.
</Accordion>

<Accordion title="Duplicate clients appearing">
  **Possible cause:** RUT was entered differently (e.g., with/without dots)
  
  **Solution:** CotizaClima normalizes RUTs automatically. If you see duplicates, they likely have different RUT values. Check and standardize the RUT format.
</Accordion>

<Accordion title="Waze button not working">
  **Possible causes:**
  - Waze app not installed
  - Missing address, city, or region data
  - Pop-up blocked by browser
  
  **Solution:** Ensure address data is complete and allow pop-ups for the CotizaClima site.
</Accordion>

<Warning>
  Client data is stored per user account. If you sign out and sign in with a different account, you'll see a different set of clients.
</Warning>
