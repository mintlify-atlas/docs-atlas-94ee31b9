## Overview

CotizaClima is a **static web application** for generating professional air conditioning quotations. It runs entirely in the browser with no backend server, using Firebase Realtime Database for data persistence and authentication.

<Info>
  The application is designed to work offline with demo data and gracefully enhance functionality when Firebase is available.
</Info>

## Architecture Pattern

### Static Frontend Only

The application follows a **pure client-side architecture**:

- **No backend server** - All logic runs in the browser
- **Static file hosting** - Can be deployed to any static host (GitHub Pages, Netlify, etc.)
- **Firebase as BaaS** - Uses Firebase Realtime Database as Backend-as-a-Service
- **Progressive enhancement** - Works with demo data when offline, syncs when online

### Key Architectural Decisions

  <Step title="Data Loading">
    Equipment and accessories load from Firebase or fall back to demo data:
    
    ```javascript app.js:237-272
    async function loadFromFirebase(url, node, authToken = '') {
      const cleanUrl = url.replace(/\/$/, '');
      const endpoint = buildFirebaseEndpoint(cleanUrl, node, authToken);
    
      try {
        showFirebaseStatus('connecting');
        const res = await fetch(endpoint);
    
        if (!res.ok) throw new Error(`HTTP ${res.status}`);
    
        const raw = await res.json();
        if (!raw) throw new Error('El nodo está vacío en Firebase');
    
        const data = normalizeFirebaseArrays(raw);
    
        if (!Array.isArray(data) || data.length === 0) {
          throw new Error('No se encontraron equipos en el nodo indicado');
        }
    
        allAC = data;
        filteredAC = [...allAC];
        renderBrandFilterOptions();
        renderACGrid();
        updateStep1NextButton();
        showFirebaseStatus('ok', `${data.length} equipos cargados desde Firebase`);
        showToast(`${data.length} equipos actualizados`, 'success');
    
      } catch(e) {
        showFirebaseStatus('error', e.message);
        showToast('Firebase: usando datos demo', 'error');
        if (!Array.isArray(allAC) || allAC.length === 0) loadDemoData();
      }
    }
    ```
  </Step>

## Error Handling Strategy

### Graceful Degradation

All Firebase operations are wrapped in try-catch with fallbacks:

```javascript app.js:267-271
catch(e) {

```
