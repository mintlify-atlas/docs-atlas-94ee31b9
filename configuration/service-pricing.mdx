## Overview

CotizaClima supports multiple service types with configurable pricing. Services are defined in `app.js` and include installation, maintenance, repair, warranty visits, and more.

---

## Service Types

Services are defined in the `SERVICES` array in `app.js`:

```javascript app.js
const SERVICES = [
  { 
    id: 'instalacion', 
    name: 'Instalación nueva', 
    desc: 'Primera instalación del equipo', 
    price: 100000, 
    icon: 'fa-hammer'

  { 
    id: 'mantencion', 
    name: 'Mantención', 
    desc: 'Limpieza y revisión general', 
    price: 30000, 
    icon: 'fa-screwdriver-wrench' 
  },
  { 
    id: 'cambio', 
    name: 'Cambio + instalación', 
    desc: 'Retiro equipo antiguo + nuevo', 
    price: 120000, 
    icon: 'fa-arrow-right-arrow-left' 
  },
  { 
    id: 'reparacion', 
    name: 'Reparación', 
    desc: 'Diagnóstico y reparación de fallas',

    icon: 'fa-gear'

  {

```

### Service Field Reference

<ResponseField name="id" type="string" required>
  Unique identifier for the service
  
  - Used internally for service selection
  - Must match keys in `SERVICE_PDF_CONTENT` if custom PDF content is defined
</ResponseField>

<ResponseField name="name" type="string" required>
  Display name shown to users in the service selection grid
</ResponseField>

<ResponseField name="desc" type="string" required>
  Short description shown below the service name
</ResponseField>

<ResponseField name="price" type="number" required>
  Default price for the service (in local currency)
  
  - Set to `0` for free services
  - Users can modify prices before generating PDF
</ResponseField>

<ResponseField name="icon" type="string" required>
  Font Awesome icon class (e.g., `'fa-hammer'`, `'fa-gear'`)
  
  - Must be a valid Font Awesome 6.5+ icon
  - Displayed in service cards
</ResponseField>

## Modifying Service Prices

### Default Prices

To change default service prices, edit the `SERVICES` array in `app.js`:

```javascript app.js
const SERVICES = [
  { 
    id: 'instalacion', 
    name: 'Instalación nueva', 
    desc: 'Primera instalación del equipo', 
    price: 150000,  // Changed from 100000 to 150000
    icon: 'fa-hammer' 
  },
  { 
    id: 'mantencion', 
    name: 'Mantención', 
    desc: 'Limpieza y revisión general', 
    price: 40000,   // Changed from 30000 to 40000
    icon: 'fa-screwdriver-wrench' 
  },
  // ... other services
];
```

### Runtime Price Variables

Some services have configurable per-unit values that users can modify in the UI:

```javascript app.js
// Default price per installation
let instalacionUnitValue = 100000;

// Default price per maintenance
let mantencionUnitValue = 30000;

// Default repair diagnostic price
let repairUnitValue = 10000;
```

These values can be changed by:
1. Users in the service selection interface
2. Importing saved quotes
3. Modifying the initial values in `app.js`

## Service Types Explained

### Multi-Quantity Services

Some services support multiple quantities in a single quote:

<CodeGroup>

```javascript Installation Service
// Installation can be added multiple times
// One installation per equipment is automatically suggested
serviceQtyMap.instalacion = equipmentCount;

// User can adjust quantity and per-installation price
const total = serviceQtyMap.instalacion * instalacionUnitValue;
```

```javascript Maintenance Service
// Maintenance can be added for multiple units
serviceQtyMap.mantencion = userSelectedQuantity;

// Price calculated as quantity × unit price
const total = serviceQtyMap.mantencion * mantencionUnitValue;
```

</CodeGroup>

### Single-Selection Services

Other services are selected once per quote:

```javascript app.js
// Only one of these can be selected at a time
selectedService = 'reparacion';  // or 'garantia', 'presupuesto', etc.

// Repair allows custom quantity and unit price
const repairTotal = repairQty * repairUnitValue;
```

### PDF Content Structure

<ResponseField name="title" type="string" required>
  Section title displayed in the PDF
  
  - Shown in bold uppercase in the PDF header
  - Example: `"Instalación de Aire Acondicionado"`
</ResponseField>

<ResponseField name="relevant" type="array<string>" required>
  Array of relevant information paragraphs
  
  - Displayed under **"Información relevante"** section
  - Each string is a paragraph
  - Use for service description, scope, and what's included
</ResponseField>

<ResponseField name="extra" type="array<string>" required>
  Array of additional information items
  
  - Displayed under **"Información extra"** section
  - Each string is shown as a bullet point
  - Use for limitations, conditions, warranties
</ResponseField>

## Service Selection Logic

### Multi-Service Mode

Installation and maintenance can be added multiple times:

```javascript app.js
function isMultiService(id) {
  return id === 'instalacion' || id === 'mantencion';
}

// Users can select quantity and price per unit
if (isMultiService(serviceId)) {
  serviceQtyMap[serviceId] = (serviceQtyMap[serviceId] || 0) + 1;
  const total = serviceQtyMap[serviceId] * unitPrice;
}
```

### Installation Auto-Suggestion

The app automatically suggests installations based on equipment count:

```javascript app.js
function preloadInstallationsFromEquipment() {
  const equipCount = getEquipCount();
  if (equipCount === 0) {
    serviceQtyMap.instalacion = 0;
  } else if ((serviceQtyMap.instalacion || 0) === 0) {
    // Auto-suggest 1 installation per equipment
    serviceQtyMap.instalacion = equipCount;
  }
}
```

## Price Calculations

### Equipment + Services Total

```javascript app.js
function calculateQuoteTotal() {
  // Equipment total
  const equipTotal = getSelectedEquipmentItems()
    .reduce((sum, item) => sum + (item.cap.price_with_tax * item.qty), 0);
  
  // Services total
  const servicesTotal = getSelectedServiceItems()
    .reduce((sum, item) => sum + item.totalPrice, 0);
  
  // Accessories total
  let accessoriesTotal = 0;
  ACCESSORIES.forEach(acc => {
    accessoriesTotal += (accQty[acc.id] || 0) * acc.price;
  });
  
  // Subtotal before discount
  const subtotal = equipTotal + servicesTotal + accessoriesTotal;
  
  // Apply discount
  const discountPct = parseFloat(document.getElementById('discountPct').value) || 0;
  const discountAmt = subtotal * discountPct / 100;
  
  // Final total
  const total = subtotal - discountAmt;
  
  return Math.round(total);
}
```
